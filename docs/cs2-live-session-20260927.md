# 실전 관측

Vault 연결 미설정. 진행 상태는 [이슈 #11](https://github.com/Jaeman-Lee/dotfiles/issues/11),
개인 설정 검토는 [이슈 #13](https://github.com/Jaeman-Lee/dotfiles/issues/13),
변경 검토는 [PR #12](https://github.com/Jaeman-Lee/dotfiles/pull/12)에서 관리한다.

사용자가 직접 한 경기를 플레이하는 동안 모니터링하고, 경기 종료 후 PC 성능과
게임 내부 커스텀 옵션까지 고려한 제안을 요청했다. 이 문서는 시작 당시 기록이며
경기 완료나 최적 설정 확정을 의미하지 않는다.

## 수집과 경계

[관측 도구](../gaming/monitor-cs2-session.py)는 실행 중인 사용자 소유 네이티브 CS2의
PID와 시작 시각을 확인하고, 5초 간격으로 메모리/스왑, CPU 코어별 누적 시간,
게임 RSS·page fault·읽기량, GPU 부하·VRAM·온도·클럭·전력, 디스크와 PSI를 수집한다.
가능하면 1분마다 게임 창 우측 상단 420×80 영역의 성능 HUD만 별도 저장한다.
게임 종료 시 또는 최대 3시간 후 관측만 끝나며 게임에 signal을 보내지 않는다.
설정 변경·프로세스 종료·키보드 입력·패킷 캡처·메모리 주입은 하지 않는다.

관측은 `cs2-live-monitor-20260927.service` 사용자 unit으로 실행한다.
중지는 `systemctl --user stop cs2-live-monitor-20260927.service`이며 게임에 영향이 없다.
실행 원본은 `~/.local/state/cs2-setup/diagnostics/live-20260927/`에 0700/0600으로
보관한다. JSONL, HUD 이미지, 개인 설정 원본은 Git에 포함하지 않는다.

HUD의 평균 FPS·최대 프레임 시간·핑·전송 손실 표본을 읽을 수 있지만
이 수집은 매 프레임 측정이 아니므로 정확한 1% low나 입력 지연 측정으로 표현하지 않는다.
온라인 경기 종료는 게임 프로세스 수명만으로 알 수 없으므로 사용자 종료 알림을 기준으로 분석한다.

## 설정 검토 범위

- FHD 120Hz, VSync, 안티앨리어싱, 텍스처/입자/그림자/앰비언트 오클루전,
  HDR/업스케일링, 실제 FPS와 프레임 제한의 균형.
- 가시성과 경쟁 플레이에 영향을 주는 옵션은 단순히 전부 낮추지 않고 비용과 이점을 비교한다.
- Logitech G102 마우스, 감도/줌 감도/조준점/레이더/키 배치/HUD/음향은
  지원 여부와 현재 메뉴 값을 확인하고 사용자 체감을 반영한다.
- 저장된 감도는 2.56, 실행 cfg에는 1.0이 있어 값이 불일치한다. 저장 파일만으로
  현재 런타임 값을 단정하지 않으며 경기 도중 덮어쓰지 않는다. 하드웨어 DPI는 아직 미확인이다.
- 지원되지 않거나 효과를 검증하지 못한 오래된 콘솔 명령은 성능 개선으로 제안하지 않는다.

## 도구 검증

Python 구문 검사 통과. 실제 실행에서 5초 간격 JSONL과 제한된 영역의 HUD 이미지가
생성되고 관측 unit이 active인 것을 확인했다. 초기 표본에서 모니터 메모리는 약 28MiB,
약 40초 구간 CPU 누적 시간은 약 0.4초였다. 이 값은 관측 오버헤드의 초기 확인이며
게임 성능 결과는 경기 종료 후 별도로 기록한다.
